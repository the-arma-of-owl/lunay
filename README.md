# 🌕 LunAy — Ay Keşif ve Anlatım Deneyimi

> **Yenilikçi Ay Keşif ve Anlatım Deneyimi**

LunAy, Ay'ı her yönüyle keşfetmenizi sağlayan interaktif bir eğitim web uygulamasıdır. Bir hackathon projesi olarak geliştirilen LunAy; tarihi haritalar, kültürel efsaneler, bilimsel veriler ve eğlenceli simülasyonlar aracılığıyla Ay'ı anlatan bütünleşik bir deneyim sunar.

🔗 **Canlı Demo:** [https://lunay.vercel.app/](https://lunay.vercel.app/)

---

## ✨ Özellikler

| Kategori | İçerik |
|---|---|
| 🗺️ **Geçmişin İzinde** | Ay'ın haritalanma serüveni, tarihteki ilk gözlemler ve astronomlar |
| 🌙 **Kültür ve Gizem** | İnançlar, mitolojiler, efsaneler ve Ay'ın karanlık yüzündeki sırlar |
| 🚀 **Keşif ve Gelecek** | Modern uzay görevleri, Artemis programı ve insanlığın Ay'daki geleceği |
| 🎮 **Oyunlar ve Simülasyon** | Dünya-Ay simülasyonu, kıyaslama oyunu ve Ay'a iniş görev oyunu |
| 📡 **Sonsuzluğa Mesaj** | Kelimelerinizi elektromanyetik sinyale dönüştürüp uzaya gönderin |

### Detaylı Bölümler

- **Geçmişten Günümüze Haritalar** — Tarihten günümüze Ay haritaları ve keşif araçları
- **Geçmişten Günümüze Ay** — İnsanlığın ilk gözlemlerinden teleskopik keşiflere uzanan yolculuk
- **Ay ve İnanç** — Mitolojilerde, dinlerde ve kadim kültürlerde ayın kutsal yeri
- **Günümüzde Ay** — Apollo görevleri ve modern bilimsel keşifler
- **Ay'ın Gizemleri** — Karanlık yüz, kraterler ve henüz çözülememiş sırlar
- **Gelecekte Ay** — Ay üsleri ve yeni bir yaşamın kapıları
- **Kıyaslama Oyunu** — Dünya ve Ay'ın gerçek boyutlarını interaktif keşfet
- **Dünya-Ay Simülasyonu** — Tutulma ve gelgit kilitlenmesini simüle et
- **Görev: Ay'a İniş** — Ay modülünü güvenli bir şekilde yüzeye indir

## 🚀 Yerel Ortamda Çalıştırma

### Gereksinimler

- [Node.js](https://nodejs.org/) (v18 veya üzeri)
- npm

### Adımlar

```bash
# 1. Depoyu klonlayın
git clone https://github.com/the-arma-of-owl/lunay.git
cd lunay

# 2. Bağımlılıkları yükleyin
npm install

# 3. Geliştirme sunucusunu başlatın
npm run dev
```

Uygulama varsayılan olarak [http://localhost:5173](http://localhost:5173) adresinde çalışacaktır.

### Diğer Komutlar

```bash
# Production build oluştur
npm run build

# Build önizlemesi
npm run preview
```
